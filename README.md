# Задание №1 
### **TaskRunner**

Планировщик задач, где прогресс выполнения визуализируется бегущим человечком вдоль таск-бара. Вместо конкретных единиц используется свободная метрика как очки прогресса.

### **1. Актуальность**
Большинство существующих планировщиков задач это простые списки с процентами или чекбоксами.
Пользователь быстро теряет мотивацию: не хватает визуальной обратной связи.

Разработка веб сайта бегущим человечком решает эту проблему: действия пользователя в реальном времени двигают персонажа по таск-бару, превращая рутину в игру.

### **2. Целевая аудитория**

Сегмент|  Потребность
-|-
Студенты| Следить за дедлайнами по учёбе, видеть прогресс по курсам
Работник| Разбивать рабочие задачи на мелкие шаги с визуальным подкреплением
Дети| Выполнения домашних дел и уроков в игровой форме 
Обыватель| Игровая мотивация по утрам или в конце дня

Портрет: от 6 лет, использует телефон ноутбук компьютер или планшет,
старается разпланировать свои действия, но быстро теряет интерес к задаче.

### **3. Функциональные возможности**

-   Создание задачи (название, описание, дедлайн)
-   Назначение "веса" задачи (например, от 1 до 10 шагов человечка)
-   Отслеживание прогресса в реальном времени
-   Визуализация (бегущий человечек движется по шкале от старта до финиша)
-   Анимация бега при выполнении задач
-   Группировка задач по тегам
-   авторизация
-   Сортировка по дедлайну и статусу
-   Поиск по названию
-   Подсчёт общего прогресса за прошедшее время сначала выполнения задания
-   Настройка персонажа (цвет)
-   Хранение данных пользователя в облаке
-   Редактирование и удаление задач
