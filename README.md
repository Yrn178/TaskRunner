# Задание №1 
### **TextMaps**

Визуальный компоновщик текста Веб сайт «TextMaps» -
редактор текста с возможностью поменять местами заметки, текст, главы,
тома и тп

### **1. Актуальность**

Большое количество людей которые пишут свой текст используют базовые
редакторы в которых для того чтобы поменять фрагменты текста местами их
нужно как-то выделять, вырезать и прочие действия занимающие в сумме
много времени, что очень муторно и замедляет процесс

Разработка веб сайта с возможностью прямо перемещать текст по своему
желанию поможет с этой проблемой.

### **2. Целевая аудитория**

  Сегмент                       |  Потребность
  ------------------------------|---------------------------------------
  Студенты                      |  При написании работы приходят идеи которые вписываются как попало и после их нужно вдумчиво структурировать
  Изучающие языки               |  Структурировать свои записи
  Писатели                      |  Пришла идея поменять местами главы в книге, нужно искать сами главы, куда именно их переместить
  Обыватель                     |  Эстетическое желание видеть аккуратные записи

Портрет: от 6 лет, использует телефон ноутбук компьютер или планшет,
ведёт блог, книгу, личные записи или записывает идеи.

### **3. Функциональные возможности**

-   Создание текстового документа (название)

-   Форматирование текста (изменение шрифта, размера, цвета; очистка текста; )

-   структурирование и оформление (добавление тегов, выравнивание текста, абзацев и колонок)

-   организация контента(Сортировка строк, удаление дубликатов)
-   выбор документа

-   авторизация

-   хранение данных

-   изменение данных

-   поиск (по тэгам, словам)

-   Возможность выделять фрагменты текста по тегам/заголовкам и перемещать их между собой

### **4. Технологии**

  -Компонент                    | -Технология
  ------------------------------|---------------------
  Фреймворк (фронт)             | React 18

  Стили                         | TailwindCSS
